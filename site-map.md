# Site Map and Page List

Compiled from `requirements.md`, the wireframes, and the UX flow diagram.

## Global elements (every page)
- Navigation bar (hamburger menu, top left, on mobile and tablet)
- Footer: full list of nav links, plus links to Substack and Instagram

## Pages
| Page | Purpose |
|---|---|
| Home | Both book covers (each linked to its product page), 2–3 upcoming events, Substack subscribe area, recent media |
| Books | Main page showing both covers with titles linked to product pages |
| Talking at Night | Product page: cover, title, author, release date, tagline, description, retailer buttons (US and UK) near top, reviews |
| People in Love | Product page: same structure as above |
| Events | Upcoming events in date order, each with title, location, guest, RSVP/ticket button; author event photo on the left |
| About | Author photo, detailed bio, Instagram and Substack buttons, embedded Substack and Instagram modules, recent media |
| Contact | Names, titles, linked emails for publicity and literary agent; social buttons |

## Navigation
- Requirements doc: Home, Books, Events, About, Contact
- Wireframes show: Home, Talking at Night, People in Love, Events, About, Contact

## OPEN QUESTION (resolve before building)
The wireframes list the two book titles directly in the nav, while the requirements doc uses a single "Books" item. Decide which one the build follows.

## User flows
See `ux-flow-diagram.png`. Key paths: Home → Book product page → external retailer; Home → Events → external venue RSVP; Home → About → Contact or external media/social.

## External links
Retailers (US: B&N, Bookshop.org, Target, Amazon; UK: Waterstones, Blackwells, Amazon), venue RSVP pages, Substack, Instagram, podcasts, YouTube, authored articles.
